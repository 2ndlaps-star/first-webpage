# My First Web Page

A simple, responsive web page built with HTML, CSS, and a touch of JavaScript.

## Files

- `index.html` — the page structure and content
- `styles.css` — styling (dark theme, responsive layout)
- `script.js` — a small interactive button
- `ARCHITECTURE.md` — the design decisions behind this project and why they were made

## View it locally

Just open `index.html` in any web browser.

Or, from this folder, start a simple local server:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000 in your browser.

## Publish it with GitHub Pages

1. Push this repository to GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, set the source to your branch and the root folder.
4. Save — your page will be live at `https://<username>.github.io/<repo>/`.
